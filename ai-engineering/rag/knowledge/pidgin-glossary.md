# Money shorthand

- **2k** = ₦2,000 · **1.5k** = ₦1,500 · **5k** = ₦5,000 · **10k** = ₦10,000
- **20k** = ₦20,000 · **1m** = ₦1,000,000
- "**500 naira**" = ₦500

# Common expressions reps and students use

- **abeg** = please
- **biko** = please (Igbo, used in Nigerian English)
- **sharp sharp** / **now now** = quickly / immediately
- **everybody** / **all of them** / **the whole class** = all eligible members
- **those wey never pay** / **who never pay** / **defaulters** = members with outstanding payments
- **make dem pay** = have them pay
- **wetin we don collect?** = how much have we collected?
- **how far with...** = what's the status of...
- **oya** = okay / go ahead
- **do am** / **create am** = do it / create it
- **no wahala** = no problem

# Dates (handled deterministically, not memorized)

Relative date phrases ("next week", "same day next week", "end of the month",
"next Friday", "in 3 days") are passed through to the backend, which resolves
them to a real calendar date in the rep's timezone (Africa/Lagos by default).
The assistant should never ask a rep to type a date in YYYY-MM-DD.

Note: reps and students use formal English just as often — the assistant must
understand both equally and should not force slang into its own replies.
